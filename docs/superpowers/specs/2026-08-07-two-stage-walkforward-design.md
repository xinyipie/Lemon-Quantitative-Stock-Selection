# 双层逐年走步短线研究设计

## 目标

验证“横截面选股”和“市场择时”拆分后，是否能在完全无未来函数的条件下形成稳定短线增量。

## 数据边界

- 输入只使用 `all_market_multi_engine_nofuture_trades_20260807.csv` 中信号日已知字段。
- `ret_3d`、`ret_5d`、`ret_8d`、`mfe_8d`、`mae_8d` 只作为结果标签，禁止进入特征。
- 每个测试年度只使用更早年度拟合；2019 年以前仅作为初始训练样本。
- 买入按 T+1 开盘，统一扣除双边交易成本。

## 两层模型

1. 横截面层：将每个交易日内的因子转成百分位，拟合相对 5 日收益。
2. 择时层：使用当日候选广度、市场状态和候选分布，拟合当天 TopN 组合的绝对收益。
3. 只有择时层预测超过训练期分位门槛时才出手。

## 验收

- 独立验证期为 2022-2024，三年均为正。
- 验证期扣费后平均收益大于 0、盈亏比大于 1.10。
- 最近期 2025-2026 至少一年为正，且整体为正。
- 成本、TopN、门槛扰动后仍有相邻组合通过。
- 分块 bootstrap 的均值不大于 0 概率低于 10%。

未同时满足以上条件时，只记录研究结果，不接入正式策略。
