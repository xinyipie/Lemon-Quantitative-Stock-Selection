# 短线与长线历史价格列设计

## 目标

在短线历史数据和长线历史数据表格中增加两列，帮助用户直接比较推荐时的可执行成本与当前价格，同时保持表格紧凑、直观。

## 展示口径

- `基准买入价`优先使用信号日后第一个交易日的开盘价，即 T+1 开盘价。
- 若尚无 T+1 行情，则回退到推荐日收盘价，并明确标注“推荐日收盘”，避免把回退值误认为实际成交价。
- `最新价`使用历史行情库中该股票最近交易日的收盘价，并显示行情日期。
- 最新价副行显示相对基准买入价的当前浮盈或浮亏；没有完整价格时显示 `-`，不猜测数据。

## 数据流

- 页面服务收集当前结果集中的股票代码和信号日期。
- 历史行情库按代码批量读取所需区间，不逐只股票调用行情接口。
- 短线和长线共用价格补充函数，统一生成 `entry_price`、`entry_price_source`、`latest_price`、`latest_price_date`和`current_price_return`。
- 只增加页面派生字段，不修改量化评分、排名、入池条件或历史策略记录。

## 排版

- 两列均采用“主价格 + 副说明”的双层紧凑样式。
- 基准买入价副行显示 `T+1开盘`或`推荐日收盘`。
- 最新价副行显示日期与当前浮盈亏，涨跌只对百分比做克制的红绿强调。
- 桌面端保持两列独立；窄屏允许副说明换行，不扩大整行高度到卡片式布局。

## 异常处理

- 停牌、退市或行情缺失时，不跨越不合理日期猜测成交价。
- T+1定义为信号日后的第一个实际有行情交易日。
- 最新价格日期必须随价格一起展示，防止停牌股票被误读为实时价格。
