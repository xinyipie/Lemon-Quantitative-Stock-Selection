# 市场状态条件化机会研究设计

## 目标

检验此前不稳定的短线机会信号是否只在特定市场状态中有效，并判断这种条件性优势能否跨年份延续。研究只使用信号日及此前可见数据，不修改正式策略。

## 固定研究口径

- 训练期：2016-01-01 至 2021-12-31。
- 独立验证期：2022-01-01 至 2024-12-31。
- 近期观察期：2025-01-01 至 2026-06-30，不参与方向选择。
- 买入：T 日收盘产生候选，T+1 开盘成交；涨停或无开盘价时跳过且不递补。
- 成本：买卖合计 0.30%。
- 每个交易日、每个画像、每个排序口径最多选择 3 只。
- 市场状态与持有期固定：BULL_TREND 8 日、BULL_PULLBACK 5 日、BEAR_BOUNCE 3 日；BEAR_TREND 不交易。
- AI、新闻和未来收益均不参与状态或排序构造。

## 搜索空间控制

只复用已经研究过的六个机会画像和九个可解释因子。每个画像、市场状态和因子只在训练期从高低两个方向中选择一个；成交额因子固定取高方向。验证期和近期观察期不得重新选择方向。

## 验收标准

候选必须同时满足：

- 训练期平均净收益大于 0.10%、盈亏比大于 1.03、至少一半年份为正且最差年份大于 -0.75%。
- 验证期交易数不少于 150 笔，活跃交易日不少于 80 天。
- 对应固定持有期平均净收益大于 0.30%。
- 盈亏比大于 1.10。
- 验证期至少三分之二年份平均收益为正。
- 验证期最差年份平均净收益大于 -0.75%。
- 相对同画像、不区分状态的验证基线，平均净收益至少提升 0.20 个百分点。

通过上述门槛仅代表进入压力测试，不代表直接上线。

## 输出

- 全部状态、画像、因子和方向的分阶段指标。
- 训练期固定后的候选配置及验证结论。
- 市场状态覆盖率和样本量审计。
- Markdown 研究报告，记录失败原因和下一步建议。
