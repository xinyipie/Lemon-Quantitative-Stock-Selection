# 股票策略研究助手 HTML 原型设计

## 目标

以现有线上项目为功能与数据底座，先制作一个完全独立的静态 HTML 原型，验证新的信息架构、页面层级和日常使用效率。原型不连接数据库、不修改 FastAPI/Jinja 页面、不替换线上版本。

用户应能在两分钟内回答四个问题：今天能不能做、重点看什么、主要风险是什么、当前策略判断有多可信。

## 原型边界

- 桌面 Web 优先，设计基准为 1440×1024；保证 1024px 宽度下仍可使用。
- 使用原生 HTML、CSS、JavaScript，不引入构建工具或前端框架。
- 使用与现有数据库字段一致的本地模拟数据。
- 原型覆盖全部现有功能的入口与主要交互，但不复刻每一张历史表的全部行和全部边缘能力。
- 提供空仓、有信号、数据滞后三种演示状态，验证页面在不同运行结果下是否仍清楚。

## 信息架构

主导航收敛为五个入口：

1. **今日**：今日结论、判断依据、市场雷达观察方向、近期策略表现、运行状态摘要。
2. **策略复盘**：页内分为短线与长线；承载历史信号、策略筛选、日期筛选、结果筛选、长线运行漏斗、生命周期和历史验证。
3. **市场观察**：页内分为行业雷达、热门龙头、消息事件、市场日报；替代当前多个超长且割裂的页面。
4. **个股研究**：股票搜索、价格趋势、财务质量、资金行为、历史信号和信号解释。
5. **系统状态**：数据库覆盖、各数据源日期、日常更新、完整重算和异常提示。

以下功能保留为详情层，不进入主导航：AI 信号解释、日报详情、策略评分理由、生命周期事件详情。

## 删除与合并

- 删除首页重复的股票搜索和历史信号大表。
- 将首页的“今日决策、最近 AI 摘要、最近信号解释”合并为“今日结论 + 判断依据”。
- 将短线正式推荐与观察候选继续分开，但在同一策略页面中切换。
- 将首页和数据状态页重复的更新操作统一到系统状态；首页仅显示同步摘要。
- 将长线页面重复的空仓解释合并为一个空状态。
- 将行业雷达、龙头、新闻和日报并入市场观察的页内标签，避免单页无限下拉。
- AI 状态不再占据信号表格整列；在详情中按需展示。

## 首页设计

首页使用“朴素研究表”视觉：白底、系统中文字体、普通标题、细分隔线和紧凑表格。无渐变、无装饰插画、无大面积深色侧栏、无卡片墙、无无意义图标。

从上到下包含：

1. 日期与同步状态。
2. 今日结论及一句原因，支持展开“查看判断依据”。
3. 今天重点看：方向、为何关注、需要确认；明确标注“市场雷达观察，不等于入池推荐”。
4. 策略近期表现：近 100 日或自定义日期，展示已完成样本数、5 日正收益率、平均 5 日收益、平均 MFE、平均 MAE和机会风险比。
5. 数据与运行状态：行情库、短线实盘、长线扫描和历史复盘日期。
6. 进入短线复盘和自选股体检的次级入口。

## 数据契约

原型只展示现有代码已经能够稳定提供的字段：

- 最新行情日期、最新实盘运行日期、短线入池数量。
- 长线 Elite/Watch 数量与最新扫描日期。
- 市场雷达提供的行业或主题观察方向及确认条件。
- 短线已完成样本数、5 日正收益率、平均 5 日收益、平均 MFE、平均 MAE、机会风险比。
- 行情、实盘信号、长线扫描、历史复盘的同步状态。
- 单股价格表现、ROE、净利润同比、负债率、资金流、换手率、量比和历史信号。
- 长线样本的 10/40/80 日收益、MFE/MAE、基准收益与超额收益。

原型不展示短线组合最大回撤、短线相对沪深 300 收益、未经定义的盈亏比、数据完整度总分或不存在的 20/60/120 日统计。

## 主要交互

- 主导航在五个视图间切换，不刷新页面。
- “查看判断依据”展开或收起规则事实。
- 策略复盘支持短线/长线标签、日期、策略和结果状态筛选。
- 市场观察支持行业雷达/热门龙头/消息事件/市场日报标签切换。
- 股票搜索显示模拟的单股研究结果和历史信号详情。
- 日期选择改变统计窗口，并同步更新样本数和提示文案。
- 原型状态切换器可演示空仓、有信号和数据滞后；该控件只用于原型验收，不进入生产设计。

## 状态与错误处理

- **空仓**：明确显示扫描已运行且无入池标的，不能伪装成数据缺失。
- **有信号**：正式入池、观察候选和市场雷达方向使用不同标签和文案。
- **数据滞后**：结论区降级为“数据待更新”，不继续给出当日判断。
- **无历史样本**：显示样本不足，不计算胜率。
- **字段缺失**：显示具体缺失项，不用笼统的“数据不足”。
- **搜索无结果**：保留输入内容并提示支持的代码或名称格式。

## 原型文件

原型放在独立目录：

```text
prototype/stock-research/
  index.html
  app.css
  app.js
```

原型不读取生产文件，不覆盖 `web_app/templates` 或 `web_app/static`。

## 验收标准

- 五个主入口均可切换，所有现有核心功能都有明确归属。
- 首页在 1440×1024 首屏内给出今日结论、重点观察、策略表现和数据状态。
- 空仓、有信号和数据滞后三种状态均可演示，文案不互相矛盾。
- 所有统计字段符合数据契约，不出现当前系统无法支持的指标。
- 日期、标签、筛选、展开、搜索等核心交互可用。
- 页面无横向溢出，1024px 宽度下仍能阅读和操作。
- 不包含交易执行、下单、仓位管理或自动交易功能。

## 后续路径

用户确认静态原型后，再决定哪些页面进入生产实现。生产阶段优先接入首页和策略复盘，沿用现有 FastAPI 服务和数据库；其他页面按原型验证结果逐步迁移，不一次性重写整个线上系统。
