# 熊市反弹弱行业修复交互研究设计

## 研究假设

市场状态条件化研究中，最接近稳定门槛的是 `BEAR_BOUNCE` 状态下按行业相对强度从低到高选择。该现象可能代表弱行业在全市场反弹阶段的均值回归，但单纯选择最弱行业缺少个股确认。

## 固定流程

1. 仅保留信号日状态为 `BEAR_BOUNCE` 的交易日。
2. 每日先选择行业相对强度处于最低 30% 的行业，行业数量向上取整且至少保留一个。
3. 在这些行业的可交易股票中，分别按五个预先指定的确认口径取每日 Top3：成交额高、当日涨幅高、距20日高点回撤大、近20日涨幅低、量比高。
4. T 日收盘产生候选，T+1 开盘成交，不可成交时不递补；固定持有 3 个交易日，往返成本 0.30%。
5. 训练、验证和近期观察区间沿用主研究设计。方向和行业阈值不得使用验证期重新选择。

## 验收

沿用市场状态条件化研究的训练稳定性和独立验证硬门槛，并要求验证期平均净收益至少比“BEAR_BOUNCE 直接按行业RS低排序”的基线高 0.20 个百分点。通过后才进入尾部依赖、成本和参数扰动压力测试。
