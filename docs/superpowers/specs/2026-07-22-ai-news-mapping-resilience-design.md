# AI 新闻映射可靠性修复设计

## 目标

修复市场雷达原始新闻存在但关键事件长期为零的问题。系统必须区分密钥缺失、请求失败、响应格式错误和字段校验失败，并在可恢复故障下自动重试。

## 设计

- DeepSeek 调用最多尝试两次，只记录安全的错误类型和 HTTP 状态，不记录密钥或响应正文。
- 新闻解析兼容纯 JSON 数组、Markdown 代码块、解释文字以及 `items/events/data/result` 对象包装。
- 映射结果必须具有非空行业、合法方向和 1-10 强度；无效新闻不得进入关键事件或板块加分。
- 当映射仍失败时，保留原始新闻浏览，并把明确失败原因写入当天缓存供页面展示。

## 验收

- 合法的代码块或对象包装响应可以生成行业映射。
- 瞬时超时后第二次请求成功时可以恢复。
- 无效字段仍被拒绝，且缓存能说明失败阶段。
