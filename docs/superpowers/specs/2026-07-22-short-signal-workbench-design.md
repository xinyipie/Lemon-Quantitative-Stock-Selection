# 短线决策工作台设计

## 目标

将短线复盘页从指标与长表堆叠，调整为先判断今日是否有信号，再查看真实推送，最后复盘历史结果的阅读顺序。

## 信息结构

- 第一屏展示今日结论、信号日期、5日胜率、平均5日收益、盘中机会和机会风险比。
- 强推荐与观察候选并列展示，无信号时保持紧凑。
- 实盘推送历史作为可展开辅助信息，不与回测样本混排。
- 历史结果默认展示已满5日样本，提供观察中、盈利、亏损、高回撤和全部筛选。
- 每条结果直接显示5日收益、MFE、MAE、信号质量与最终结论，长原因按需展开。

## 约束

- 不修改选股、评分和风险规则。
- 不把历史回测结果表达为今日推荐。
- 桌面端避免横向溢出，移动端允许结果表局部横向滚动。
