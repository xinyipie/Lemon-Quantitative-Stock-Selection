# 十年样本外验证设计

## 背景

当前短线策略研究已经产生多版结果：v19 在 2025 全年和 2026 上半年表现很好，但在 2023、2024 失效；v9 交易数和收益弹性较强，但弱市胜率和回撤不理想；v23/v25/v27/v28 各自解决了部分年份或部分风险，却没有证明能稳定覆盖未知未来。

继续用 2025/2026 的结果反复调参，会把“未来上涨”偷换成“历史切片拟合”。本阶段目标从追求某一版历史收益最高，切换为建立防过拟合的十年验证框架。

## 目标

建立一个面向短线选股的样本外验证流程，评估策略是否真的能在未知市场里筛出未来 3-5 个交易日更容易上涨、收益为正、回撤可控的股票。

## 核心原则

1. 规则必须事前成立：只允许使用买入日前已经可见的数据。
2. 不能按测试年份反向调参：2025-2026H1 作为最终样本外验收，不用于改阈值。
3. 不以单年暴利为目标：优先看跨年份稳健性、最差年份亏损、交易数、最大回撤和连续亏损。
4. 允许少推，但不能极端少推：交易数太少时胜率没有统计意义。
5. 因子必须有交易解释：不接受只因为某年回测好而加入的阈值。

## 推荐数据切分

| 区间 | 用途 | 说明 |
|---|---|---|
| 2016-2019 | 研究/发现 | 观察因子稳定性，设计候选策略 |
| 2020-2021 | 第一轮样本外验证 | 策略规则冻结后验证，不按结果改 |
| 2022-2023 | 压力测试 | 检查熊市/弱市是否乱推亏损票 |
| 2024 | 独立弱修复验证 | 检查弱修复行情下是否能少亏或赚钱 |
| 2025-2026H1 | 最终封存验收 | 只验收，不再反向调参 |

## 数据风险

1. `stock_basic` 当前下载逻辑使用 `list_status='L'`，十年回测会产生幸存者偏差；退市股和历史曾上市股票可能缺失。
2. 财务静态文件若只保留当前/近期开奖，历史回测可能存在未来函数风险；短线技术策略可先以行情、换手、资金流、指数为主。
3. `index_daily` 当前缺到 2026-06-25，而 daily 到 2026-06-30，补齐前 2026H1 行业/大盘过滤可能不完整。
4. 1990/1991 零散缓存会干扰自动探测区间，批量回测必须显式指定 2016-2026，而不是直接用最早/最晚文件名。

## 验收指标

每个策略、每个年份至少输出：

| 指标 | 用途 |
|---|---|
| 总收益率 | 看是否真的赚钱 |
| 胜率 | 看 3-5 天上涨概率是否改善 |
| 交易数 | 防止用极少样本伪造高胜率 |
| 最大回撤 | 衡量踩坑代价 |
| 单笔平均收益 | 衡量推荐质量 |
| 最大连续亏损 | 衡量实盘心理压力 |
| hit_3pct / hit_5pct | 衡量买入后短窗口兑现能力 |
| avg_mfe / avg_mae | 衡量上涨空间和下跌风险 |

## 候选策略范围

第一轮只评估已有版本，不新增因子：

| 策略 | 目的 |
|---|---|
| v9 | 高交易数、强收益弹性基线 |
| v19 | 2025/2026 强收益母体 |
| v23 | 2024 当前最好结果 |
| v25 | v19 保守防守版 |
| v27 | 2024/2025/2026 较均衡版 |
| v28 | 高纯度防坑门，但交易数偏少 |

统一口径优先使用 `hold=3`、`Top1/Top2`；v9 保留现有 `hold=8` 对照，但不能与 3 日策略直接混排。

## 决策标准

策略进入下一轮必须满足：

1. 2023-2026H1 任一完整年度不能出现无法解释的大幅亏损。
2. 2025/2026H1 保持正收益，但不得以牺牲 2023/2024 为代价。
3. 单年交易数少于 5 笔时，该年只作为风险提示，不作为胜率证明。
4. 若某策略只在强行情赚钱，应标记为“强行情模块”，不能作为全市场默认策略。
5. 最终线上策略可以是状态机组合：不同市场环境启用不同候选策略，弱市允许空仓。
