# v36 快照第一名规则验证

## 目的

第二档不再手工微调单一阈值，而是先用 `reports/consensus_snapshot_v19_v25_v27_20260703.csv` 做快照搜索，再把少数候选接入正式回测。

本轮扩展了 `research/consensus_rule_search.py`：

- 支持 `filter_cautious_down_friction`。
- 支持 `min_cautious_friction_pattern`，用于谨慎摩擦区高形态例外。
- 将上述条件纳入规则名称和搜索输出，方便复盘。

快照搜索输出：

- `reports/consensus_rule_search_v35_plus_20260704.csv`
- `reports/consensus_rule_search_v35_plus_20260704.md`
- `reports/consensus_rule_search_v35_plus_20260704.json`

## 快照搜索发现

扩展搜索共评估 4608 条规则。按默认评分第一名是：

`top2|votes>=2|heat>=50|vol<=2.5|no_cautious_friction|friction_pattern>=60`

但固定 5 日收益口径下，它只有：

- 交易数：86
- 胜率：59.30%
- 近期胜率：61.70%
- 总收益：+202.70%

进一步用硬条件筛选：

- `win_rate >= 70`
- `recent_win_rate >= 70`
- `bad_year_return >= 0`
- `total_trades >= 20`

没有规则通过。即使降到 `total_trades >= 10`，仍没有同时满足近期胜率和全局胜率的规则。

这说明快照固定 5 日口径下，简单放宽候选池无法得到“又多又高胜率”的规则；正式回测的动态退出可能改善结果，但快照层面不支持盲目扩容。

## v36 正式候选

为了验证快照最高胜率附近的规则，接入 v36：

## 结论

v36 Top1 的单笔质量略高，2025 平均收益从 v35 的 +5.73% 提升到 +6.54%，5% 命中率也从 68.75% 提升到 77.78%。但它砍掉了太多有效交易，2025 总收益从 +136.95% 降到 +74.77%。

因此：

- v36 不升主线，不继续跑全十年。
- v36 可作为“极保守少推版”参考，但不符合当前目标里的“空窗期少、收益也要高”。
- v35 Top1 仍是当前主基线。

## 下一步

继续优化不能只靠压缩候选池。更有希望的方向是做二级排序或出场适配：

- 在 v35 候选内找更好的 Top1/Top2 排序因子，而不是继续过滤。
- 重点研究 v35 被保留但收益较弱的样本，找能提高 Top2 胜率的排序信号。
- 保留 2019/2022/2023 空窗压力测试，任何扩容都不能打开这些年份的亏损样本。
