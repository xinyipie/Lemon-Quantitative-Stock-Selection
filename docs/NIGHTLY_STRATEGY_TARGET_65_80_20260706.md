## 重要修正：未来函数防护

中途粗筛出现过 80%+ 胜率、100 笔以上的规则，但它们把 `pre_T7_*` 路径确认用于更早的 T1/T3/T5 买点，属于未来函数。

已在 `research/broad_engine_factor_miner.py` 和 `research/broad_engine_rule_union_search.py` 修正：

- 使用 `pre_T7_*` 条件时，强制 `entry_bucket=T7`。
- 使用 `pre_T5_*` 条件时，强制 `entry_bucket=T5`。
- 使用 `pre_T3_*` 条件时，强制 `entry_bucket=T3`。

修正后才出现上面的合法候选。

## 当前判断

今晚的数值目标已经有候选满足：`胜率>=65%` 且 `笔数>80`。

但它还不应直接上线：

- 年度分布不均，收益主要集中在 2025。
- 2020、2024 表现弱，说明仍受市场年份结构影响。
- 候选 A 的两个扩展规则是同条件不同排序并集，解释性弱于候选 B。
- 候选 B 更像可讲清楚的策略，但亏损年份更多。

## 下一步

1. 对候选 A/B 做 2016-2026 分年样本清单审计，确认亏损年份失败共性。
2. 对候选 B 单独导出交易明细和年度分布，优先看是否能降低 2020/2024 损失。
3. 引入年度稳健约束：目标不只是总胜率过线，还要限制亏损年份数量和单年最大回撤。
4. 如果继续优化，优先围绕 `weak_momentum + 强板块承接 + T5不破位`，而不是回到泛候选池。
