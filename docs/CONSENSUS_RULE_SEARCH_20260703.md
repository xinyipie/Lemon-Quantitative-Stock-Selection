# 共识快照规则搜索结果

## 目的

在 `reports/consensus_snapshot_v19_v25_v27_20260703.csv` 上做秒级规则搜索，筛选值得进入正式 `backtest_v2.py` 十年矩阵的候选。

本搜索只使用固定 5 日收益、MFE、MAE 做候选筛选，不替代正式回测。

## 新增脚本

`research/consensus_rule_search.py`

本轮命令：

```bash
python research\consensus_rule_search.py --snapshot reports\consensus_snapshot_v19_v25_v27_20260703.csv --output reports\consensus_rule_search_20260703.csv --min-trades 20
```

输出：

- `reports/consensus_rule_search_20260703.csv`
- `reports/consensus_rule_search_20260703.md`
- `reports/consensus_rule_search_20260703.json`

有效规则数：1136。

## 搜索评分口径

核心目标：
- 近期 2025/2026H1 胜率和收益尽量高。
- 2016/2022/2023 坏年收益不能明显亏。
- 交易数不能像 v30 一样太少。
- 平均 MAE 尽量低。

评分不是最终收益目标，只用于给候选排序。

## 候选解释

### 候选 A：覆盖型 v32

规则：

```text
Top2
consensus_votes >= 2
limit_up_count >= 50
volume_ratio <= 2.5
```

优点：
- 样本 94，明显多于 v30。
- 坏年合计 +0.63%，比 v29 的坏年亏损好。
- 近期收益 +164.40%，保留一定弹性。

风险：
- 快照 5 日胜率只有 56.38%，不是 70% 型。
- 正式回测可能依赖退出规则提升结果，必须验证。

### 候选 B：防守型 v33

规则：

```text
Top2
consensus_votes >= 2
limit_up_count >= 40
sector_ma10_ratio 不在 46-70
```

优点：
- 快照胜率 58.82%，坏年收益 +2.76%，MAE -3.31%，防守更好。
- 覆盖 85 笔，比 v30 多。

风险：
- 近期收益低于候选 A。
- 与 v30 思路接近，仍可能在正式回测里交易数偏少。

## 当前判断

搜索没有找到“快照层 70% 胜率且交易数足够”的规则。比较现实的路线是：

1. 先把候选 A 接成正式 `consensus_profile`，跑关键年份和十年矩阵。
2. 如果候选 A 的正式回测能靠退出规则把 2025/2026H1 胜率拉高，同时坏年不亏，继续优化。
3. 如果候选 A 失败，再测候选 B。

不要直接把这些规则上线。它们只是快照层候选。
