# v34 Cautious 跌停摩擦门十年验证（2026-07-04）

## 规则

v34 继承 v33 的三版本共识和双车道广度门：

- v19 / v25 / v27 至少 2 票共识。
- 防守核心车道：`limit_up_count >= 60`，且 `sector_ma10_ratio` 不在 46-70 的中性广度区间。
- 中性广度扩展车道：`sector_ma10_ratio` 在 46-70，`limit_up_count >= 70`，`volume_ratio <= 2.3`，且 `limit_down_count <= 3` 或 `limit_down_count >= 20`。

v34 新增一层 cautious 模式摩擦门：

- 当 `macro_mode == cautious` 且 `limit_down_count` 在 5-19 之间时过滤。

设计动机：v33 的 2019 两笔亏损都出现在 `macro_mode=cautious`，且跌停数处于不上不下的 5-19 区间；2021 的一笔大亏也有同样结构。这个过滤是把 v33 的“中性广度分歧结构”思想推广到 cautious 模式，而不是单独按年份硬拟合。

## 判断

v34 Top1 是当前最强主候选：

- 全十年 24 笔，活跃年份平均胜率 97.50%，总收益 +180.98%。
- 没有亏损年份；2016-2019、2022-2023 空仓。
- 2025 保持 v33 的主收益：16 笔，87.50%，+136.95%。
- 2026H1 少一笔，但剩余 3 笔仍 100%，+17.06%。
- 买入后 3/5 日命中率明显高于 v33/v30：活跃 Hit3 98.75%，Hit5 83.75%。

主要代价：

- 交易数从 v33 Top1 的 29 笔降到 24 笔，容量更保守。
- Top2 虽然也无亏损年份，但 2025 胜率只有 69.23%，收益明显弱于 Top1，不建议作为主推档。

当前建议：

- 主推研究候选：`v34_consensus_cautious_down_friction_top1_hold3`。
- Top2 仅作为观察档，不作为“高胜率高利润”的默认推荐。
- 下一步如果继续优化，应优先做容量扩展，但必须以不破坏 v34 Top1 的无亏损年份和 2025/2026H1 表现为约束。
