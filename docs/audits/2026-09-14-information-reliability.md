## 本轮实际修改

| 模块 | 文件 | 修改与效果 |
|---|---|---|
| 行情下载 | `data_downloader.py` | 局部标准化股票基础字段；symbol 保留前导零，日期规范化；部分状态合并旧缓存也处理混合类型；无有效主数据/非法主键抛出异常，保护原缓存，不能假报成功 |
| 公共时效 | `market_data_clock.py` | 根据完整交易日历计算最低应有行情日；周末节假日不按工作日猜测；日历缺失、行情滞后、未来日期明确失败 |
| 日报入口 | `daily_research_report.py`、`daily_report/service.py` | 支持自定义缓存目录；AI 调用前检查数据日期；校验初稿、一次修订及降级稿，只有合格内容发布；失败不覆盖旧版本 |
| 事实与文章 | `daily_report/facts.py`、`publication.py`、`writer.py` | 历史绩效标明回测来源、样本与区间及未重跑状态；中文数字、可见标题、引用均校验；拒绝不符合来源的数字与已验证断言；合理舍入 |
| 证据快照 | `daily_report/publication.py`、`service.py` | 按段保存有限公开依据，安全过滤外链；未知来源时间留空；保存发布时交易日核验结果，不保存完整内部对象 |
| 更新编排 | `daily_web_update.py` | 有效行情未追平最低目标则中断后续生成；不再用请求日期冒充实际最新日期；缓存参数贯通日报子进程 |
| 日报页面 | `web_app/services/report_service.py`、`templates/report_detail.html`、`reports.html`、`static/app.css` | 提示历史/时效不可核验；旧文无来源快照明确告知；新增段落依据展开、安全来源链接、章节导航和阅读口径 |
| 市场雷达 | `web_app/services/sector_service.py`、`templates/sectors.html` | 缺行业/消息/概念日期不得显示已对齐；数据不足不能显示可研究或无风险的正面暗示；消息明细折叠，保留摘要及导航 |

## 验证过程与结果

- 股票主数据真实 Parquet 回归先复现生产 ArrowTypeError，再通过混合类型、退市、缺失值、非法主键与缓存保护测试。
- 日报验证先证明旧实现会直接发布不合格稿，再验证修订/降级/拒绝及保留旧版本。
- 时效覆盖：周一用上周五、连续假期、日历缺失/不完整、18 点前后、自定义目录、过期数据在事实与 AI 调用之前停止。
- 独立审查发现并修复：中文数字校验边界、章节标题漏检、历史“已验证”错误断言、主数据异常未传播、自定义日历路径、来源时间误填。
- 全套 Python 回归：`python -m pytest -q --disable-warnings`，1037 passed、22 skipped、5 subtests passed；随后新增一道过期日报集成测试，相关 27 项通过。既有环境有 Python 3.14 / Pydantic 插件兼容提示。
- 独立复审：先前 6 项问题已关闭，复审针对测试 66 passed，无新增确定阻塞。
- 前端脚本：`node --test tests/js/*.test.cjs`，5 passed。
- `git diff --check` 通过，仅 Git 换行规范提示。

## 真实浏览器验收

本地隔离 SQLite 副本与明确标记的验收示例，未写入生产数据：

1. 新版日报能打开，报告日期/行情日期分开，缺日历提示可见。
2. 点击“查看本段依据”可展开依据、来源时间和安全外链。
3. 点击“上一篇”进入已有历史日报，显示历史记录和来源快照缺失说明。
4. 390×844 窄屏标题、警示和正文可阅读；章节导航横向滚动，正文未见横向裁切。
5. 市场雷达导航可达，缺数据时显示停止判断；消息明细在固定验收快照上能展开驱动、风险与个股区。

浏览器验收中额外发现“缺行业日期但其他日期相同”仍被视为对齐，已补回归修复。
