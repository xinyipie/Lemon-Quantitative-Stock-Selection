# 真实浏览器操作审查（2026-09-07）

## 环境与覆盖边界

在当前未提交工作树启动 `deploy.gateway:app`，通过 Codex 内置 Chromium 浏览器实际点击、输入、提交、翻页、展开和读取截图。真实数据服务为 `http://127.0.0.1:8766/stock/`，只读模式；更新/AI 写请求返回 403。未访问外部行情或付费 AI 服务，也未更改真实信号与行情数据库。

共检查 8 个主导航页面及 AI 解释详情，共 9 类业务页面。桌面使用浏览器默认宽度，补充 390×844 视口检查数据页、菜单、单股查询；检查后恢复默认视口。没有声称覆盖所有设备、所有参数组合或所有数据库状态。

真实库行情截至 2026-06-30，实盘运行日为 2026-07-23，当前没有强推荐/长线活跃标的，雷达目标日没有新闻。相应非空卡片、原文阅读和 AI 实际生成内容无法在这份真实数据上完整验收。写流程另使用 `fixture_server.py` 在 8767 端口提供真实页面/路由，仅将更新任务和 AI 生成替换为内存模拟；模拟结果不代表外部服务接通。

截图、DOM 和 HTTP 补充诊断保存于 [证据目录](browser-2026-09-07/)。浏览器对某些 4xx/5xx 导航保留旧页面，因此下文同时记录浏览器表现与 HTTP 状态，避免把“没有跳转”误判为按钮事件未触发。

## 确认问题

### B-01（P1）：指数查询触发 500，未完成承诺的多品种体检流程

复现：进入“单股体检”，输入“沪深300”，点击“查询”。浏览器仍保留平安银行旧页面；服务日志显示 `jinja2.exceptions.UndefinedError: 'dict object' has no attribute 'pe_ttm'`，HTTP 补充检查确认 `/stock/stock/沪深300` 返回 500。

根因：`stock_history_query.py:64-66` 为指数返回空的基本面/资金/财务字典，`web_app/templates/stock_detail.html:153` 等处仍按股票访问必填属性，`web_app/services/ui_service.py:70` 对 Jinja Undefined 执行 `float()`，只捕获 TypeError/ValueError，未处理缺字段。不能只修 PE 一项，应按资产类型渲染并规范空字段。

证据：[手机输入后旧页面](browser-2026-09-07/13-mobile-index.png)、[HTTP 诊断](browser-2026-09-07/http-diagnostics.json)。无效输入 `abcdef` 的“未找到该品种”分支可以正常展示；ETF 基础表为空，`510300` 返回空结果不能视为 ETF 正常详情验收。

### B-02（P2）：价格图收盘线不可见

华亚智能和平安银行的真实截图只显示 MA20/MA60，收盘走势缺失。DOM 检查发现 `.chart-close` 的路径长 1628 个字符，但计算样式 `stroke: none`，根元素 `--accent` 为空；另外两条线有正常 RGB stroke。

根因：`web_app/static/app.css:398` 使用未定义的 `var(--accent)`，`:419` 的图例也使用该变量；当前根变量定义的是 `--blue`。`stock_detail.html:76` 的路径数据本身存在。这会隐藏用于判断实际价格波动的主曲线。

证据：[单股图表](browser-2026-09-07/05-stock.png)、[手机图表](browser-2026-09-07/13-mobile-index.png)。建议统一颜色变量并检查实际计算样式，不能只断言 HTML 中存在 SVG。

### B-03（P2）：首页中央“单股体检”快捷入口 404

在 `/stock/` 点击中央决策卡的“单股体检”，href 为 `/stock/000001`，正确地址为 `/stock/stock/000001`。HTTP 实测前者 404，侧栏同名入口正常。

根因：`web_app/services/signal_service.py:1049` 返回子应用路径，`web_app/templates/dashboard.html:51` 直接输出 `item.href`，没有应用挂载前缀。中央 `/signals` 和 `/longterm` 也使用旧路径，但带 Referer 时被 gateway 的兼容跳转救回，实际结果为 200；不能把这两个也一概写成 404。

证据：[首页截图](browser-2026-09-07/01-dashboard.png)、HTTP 诊断。建议动态链接与侧栏统一使用挂载路径函数。

### B-04（P2）：数据状态页更新没有进度和错误反馈

数据状态页点击“更新到最新交易日”，请求被拒绝后按钮恢复，但文案仍是“当前状态：同步完成。”，没有出现 403 错误；首页相同操作能显示错误。

根因：`web_app/templates/db_status.html:17` 的外层 section 缺少 `data-update-status-url`；`base.html:52` 只选择带此属性的 panels，`:67-107` 的进度更新和 `:180-191` 的失败展示都遍历此集合。表单确实提交，但数据页的消息、错误框和轮询按钮均不属于集合。初始模板还只显示原始 `update_status.message`，忽略行情过期的装饰状态。

证据：[数据状态](browser-2026-09-07/11-db.png)、[窄屏状态](browser-2026-09-07/12-mobile-db.png)。建议补齐统一状态面板结构，同时测试此页成功、运行中和失败三种状态。

### B-05（P2）：正文分区导航沿用侧栏浅色文字，对比度不足

雷达、长线和日报返回导航在浅色底上显示很淡。真实计算样式：分区链接文字 `rgb(203,213,225)`，背景 `rgb(248,250,252)`。这组颜色的对比度约 1.4:1，难以阅读。

根因：`web_app/static/app.css:92-103` 的全局 `nav a` 原本适配深色侧栏，却同时影响正文导航；`:536-543` 的 `.page-section-nav a` 只改背景，没有改文字颜色。建议把侧栏规则限定到 `.sidebar nav`，为正文导航设置独立颜色。

证据：[雷达](browser-2026-09-07/08-radar.png)、[长线](browser-2026-09-07/07-longterm.png)、[日报返回入口](browser-2026-09-07/10-report-detail.png)。这里只核验已观察颜色，不代表完成全部无障碍标准审计。

### B-06（P2）：过期数据仍产生“今日/明日”的行动语气

行情落后 69 天时，首页仍写“今日决策”“今日不宜开新仓”，短线页写“今日无强推荐”，龙头页写“明日偏向”。首页确有日期及滞后警告，因此问题不是完全隐瞒数据日期，而是主结论与数据时效仍矛盾。

例如 `dashboard.html:43` 固定写“今日决策（最近运行决策）”；龙头/短线也沿用当前时态。建议数据过期时将标题改为明确的“截至 YYYY-MM-DD 的历史判断”，不能把空结果推导成今天已经扫描且应防守。雷达“已对齐”只代表模块对齐到旧目标日，也应与“是否最新”明确区分。

证据：01、04、07、08 截图和对应 DOM。历史日报明确标出报告日期与行情日期，未将其归为此问题。

### B-07（P3）：权限拒绝与错误流程缺少面向用户的说明

只读首页显示英文 `Remote writes are disabled`；解释页“重新生成解释”是普通 POST，返回 JSON 403，浏览器保留旧文档，没有页面内错误解释。权限拦截本身是预期行为，不应取消；应在只读模式清楚标记操作权限，或提供中文错误页/页面内反馈。

证据：[首页拒绝](browser-2026-09-07/02-write-denied.png)、[解释页保留旧内容](browser-2026-09-07/06-explanation-denied.png)、HTTP 诊断。AI 下游被替换为无操作时，成功 POST 能回到正确的 `/stock/explain/...`，挂载后的成功跳转正常。

### B-08（P3）：开始日期晚于结束日期没有校验说明

短线筛选输入开始 `2026-06-30`、结束 `2026-01-01`，页面把它当作普通空结果，所有计数变零，未指出区间倒置。`ui_service.py:42-44` 只规范字符串，页面查询未统一校验日期关系。建议在提交前后都报告可读的区间错误。

证据：[倒置日期 DOM](browser-2026-09-07/17-reversed-dates-dom.txt)。普通区间和空查询能正常工作，未发现数据写入风险。
