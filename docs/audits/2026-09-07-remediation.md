## 启动与数据准备

在真实运行环境中设置 `TUSHARE_HTTP_URL` 为服务提供方确认可用的 HTTPS 接口。本项目没有替你猜测或验证一个新的服务地址；留空会阻止联网初始化。令牌继续通过环境变量注入。

Web 对外部署设置长随机 `STOCK_WEB_TOKEN`，浏览器以 Basic 密码输入该令牌（用户名任意），接口可用 Bearer。应通过 HTTPS 访问。未配置令牌时写入禁用；仅本机开发可显式设置 `STOCK_WEB_ALLOW_LOCAL_WRITE=1`。可选 `STOCK_PRODUCT_WORK_DIR` 指定原型目录。

完整更新默认包含财务；`--skip-financial` 显式跳过，`--financial-only-force` 在保留历史记录的基础上重刷财务。自定义数据目录用 `--cache-dir`。财务批量下载依赖当前数据服务支持项目使用的批量股票代码请求，未引入逐股接口循环。

严格历史回测需要 `data/cache/stock_basic_history/YYYYMMDD.parquet` 中对应交易日的完整基础信息，包含时点名称、行业、上市/退市日期和完整状态来源标记。下载器从现在开始保存当日快照，不能据此恢复过去的名称和行业。缺少历史快照会明确报错；显式关闭 `strict_point_in_time` 的兼容研究会标记静态数据来源，不能据此声称消除了历史偏差。本地实盘数据读取使用当前静态信息。

修正退出逻辑后必须重新跑回测才能得到新统计。缺少精确涨跌停价时仍使用引擎原有阈值近似，尚不能完整覆盖所有板块及特殊交易日规则；每日 OHLC 也不能确定盘中路径。无法退出会中止该次计算，避免把不可实现的退出算成完成交易。
