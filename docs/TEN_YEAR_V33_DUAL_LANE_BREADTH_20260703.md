# v33 双车道广度门十年验证（2026-07-03）

## 规则

三版本共识仍沿用 v19 / v25 / v27，至少 2 票命中。v33 在共识后增加双车道过滤：

1. 防守核心车道：
   - `limit_up_count >= 60`
   - `sector_ma10_ratio` 不在 46-70 的中性广度区间
2. 中性广度扩展车道：
   - `sector_ma10_ratio` 在 46-70
   - `limit_up_count >= 70`
   - `volume_ratio <= 2.3`
   - `limit_down_count <= 3` 或 `limit_down_count >= 20`

设计意图：保留 v30 的坏年防守，同时只在中性广度里放行“干净强势”或“强分歧修复”的票，避免 v32 在 2016/2023 漏水。

## 判断

v33 Top1 是目前最强候选：

- 2025：16 笔，87.50% 胜率，+136.95%。
- 2026H1：4 笔，100.00% 胜率，+21.11%。
- 全十年：29 笔，活跃年份平均胜率 75.70%，总收益 +167.27%。
- 坏年防守：2016、2017、2018、2022、2023 空仓。

但它还不是最终可宣布完成的版本，因为 2019 有 2 笔亏损，总收益 -9.44%。下一步应该只针对 2019 的两笔亏损做归因，优先寻找能过滤这两笔、且不伤 2025/2026H1 主收益的可解释条件；如果找不到，就保留 v33 Top1 作为当前主候选，而不是继续堆过拟合规则。
